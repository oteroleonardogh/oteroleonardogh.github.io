# Leonardo Otero - Portfolio

Personal portfolio and technical blog built with Astro, React, and Tailwind CSS.

## Live demos

The site includes interactive components that showcase real engineering work:

- **Algorithmic Trading Simulator** - Live trading bot with real-time order execution, portfolio management, and a PANIC button for emergency reallocation
- **Live Playground** - TypeScript code editor that calls Claude API to generate encounter suggestions
- **Load Testing Dashboard** - k6 simulation with 200 virtual users across 5 API endpoints
- **Infrastructure Cost Modeling** - Interactive calculator with MAU-based projections and PERT analysis

## AI-augmented architecture

19 custom AI skills powered by Claude Code and Codex that automate the entire development lifecycle:

```text
PLAN                    BUILD                    SHIP

/read-confluence        /create-pr               /create-doc

```
